# priv/dev/lab_fixtures/

Reserved location for bulky JSON fixture payloads used by `dev/lab/fixtures.ex`
(`DevLab.Fixtures`) — the dev-only Component Lab fixture catalog (Phase 37,
D-16/D-17).

## Rules

- **Dev-only, never shipped to Hex.** This directory lives under `priv/dev/`,
  which `mix.exs` `package/0` intentionally excludes from `files:` (see the
  comment above that list). It is a maintainer tool, not adopter-facing data.
- **Never `priv/fixtures/`.** `priv/fixtures/` *is* shipped to Hex
  (`package/0` includes it for `Scoria.SupportJourney`'s runtime-safe
  fixtures). Bulky lab-only JSON must never be placed there — that boundary
  is proven by `test/scoria_web/dev_lab_boundary_test.exs`
  ("no dev/lab/fixtures* source references priv/fixtures/").
- **`@external_resource` required.** Any `.ex` file under `dev/lab/` that
  reads a JSON file from this directory must declare
  `@external_resource "priv/dev/lab_fixtures/<file>.json"` so a malformed or
  edited fixture fails `mix compile` under `:dev` instead of at first render.
- **Deterministic only.** No file here should be regenerated by a script that
  reads the database, the current time, or any other nondeterministic source
  (D-17) — the lab must render identically on every boot.

As of Phase 37 Plan 01, `DevLab.Fixtures` needs no JSON payload — every
scenario is a plain literal Elixir map. This directory is reserved for future
scenarios where inline map literals would become unwieldy (e.g. very large
dense-data specimens).
