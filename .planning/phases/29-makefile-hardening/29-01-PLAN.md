## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator shell → Docker daemon | `make clean`/`nuke`/`fleet` invoke `docker compose` / `docker ps`; the daemon is shared across sibling repos/instances on the same machine |
| Makefile recipe → external `proxy` network | the shared Traefik network is `external` and shared across all instances; teardown must never remove it |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-29-01 | Destruction | `nuke` teardown wiping volumes outside this instance | mitigate | D-05: `docker compose down -v` is scoped to `$(COMPOSE_PROJECT_NAME)` by Compose namespacing — never a hand-rolled `docker volume rm` list. Enforced by the DXCLI-02 negative gate `grep -nE "volume prune\|system prune" Makefile` == 0 (Task 2 acceptance) and the forbidden-string ban on `volume rm` name lists. |
| T-29-02 | Destruction | global prune (`docker system prune` / `docker volume prune`) destroying sibling repos' data | mitigate | Hard-forbidden in any target; Task 2 acceptance gate requires `grep -cE "volume prune\|system prune" Makefile` == 0. |
| T-29-03 | Repudiation / operator error | `nuke` destroying data without the operator understanding scope or cold-recompile cost | mitigate | D-06: dynamic named-scope warning enumerates real volumes (`docker compose config --volumes`), names `$(COMPOSE_PROJECT_NAME)`, and states the cold-recompile cost BEFORE the destructive command. No TTY prompt by design (target name is the signal); CI/non-TTY safe. |
| T-29-04 | Destruction | teardown removing the shared external `proxy` network / Traefik | accept | `docker compose down -v` only acts on project-namespaced resources; `external` resources are never removed by Compose. No mitigation code needed — this is a Compose invariant, not a Makefile choice. |
| T-29-SC | Tampering | npm/pip/cargo installs | accept | This phase installs ZERO external packages (RESEARCH "Package Legitimacy Audit: Not applicable"). No install tasks; no legitimacy checkpoint required. |

This is a dev-tooling Makefile, not a network service — the threat surface is teardown blast-radius and global-prune avoidance only. No web/auth/input-validation threats apply.
</threat_model>
