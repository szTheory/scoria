## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Runtime -> Semantic cache | Requests cross from public runtime inputs into durable reuse state |
| Semantic cache -> Database | Tenant-partitioned rows and lifecycle events become durable truth |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-44-01-01 | Information Disclosure | entry lookup filters | mitigate | Require `tenant_id` on every lookup/write and index around tenant-first filters. |
| T-44-01-02 | Tampering | entry lifecycle history | mitigate | Keep append-only event rows instead of mutating away provenance. |
| T-44-01-03 | Repudiation | writeback rejection reason tracking | mitigate | Persist stable `reason_code` values with workflow/span lineage. |
</threat_model>
