| Runtime metadata -> eligibility engine | Scoria decides whether a run is safe to reuse semantically |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-44-02-01 | Elevation of Privilege | lane admission | mitigate | Require an explicit lane module; prompt policy cannot opt a run into semantic reuse by itself. |
| T-44-02-02 | Information Disclosure | scope derivation | mitigate | Default to tenant scope and narrow to actor scope when personalization evidence exists. |
| T-44-02-03 | Tampering | bypass reason reporting | mitigate | Use stable machine reason codes so runtime and later UI layers cannot blur unsafe decisions into prose. |
</threat_model>
