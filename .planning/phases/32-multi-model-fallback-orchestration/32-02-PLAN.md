defmodule Scoria.Orchestrator do
  @doc """
  Calls the underlying LLM via a static fallback chain on failure.
  Optionally accepts `:req_llm_module` within `options` for test stubbing.
  """
  def generate_text(model_spec, prompt, options \\ [])
  def generate_object(model_spec, prompt, schema, options \\ [])
end

# Architecture Guidelines
- Callers must load `orchestrator_module` dynamically (via `Application.get_env` or `attrs`).
- Callers must remove explicit appending of `Scoria.Req.Steps.req_options/1` as `Scoria.Orchestrator` manages this internally per-attempt.
- For async testing (e.g., in `JudgeRunnerTest`), pass the `req_llm_module` provided in `attrs` downstream to `Scoria.Orchestrator` via `options` (e.g. `[req_llm_module: rlm]`).
