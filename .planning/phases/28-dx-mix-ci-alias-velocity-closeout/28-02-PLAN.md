<!-- The computation contract (D-D2), exact and load-bearing. -->

Critical path = SUM of stage maxima along the dependency chain:
  policy → build → max(test, ratchet, knowledge, connector, full-suite shards) → verify-summary
using each job's (completedAt − startedAt) = ACTIVE run time (EXCLUDES queue time).
For matrix lanes (full-suite ×4) take the SLOWEST shard.
Run-level wall-clock headline = max(completedAt) − min(startedAt) across all jobs.
NEVER quote summed billable minutes as wall-clock.

Capture commands (D-D2):
  gh run view <RUN_ID> --json databaseId,headSha,createdAt,jobs,workflowName,url > <out>.json
  jq -r '.jobs[] | [.name, ((.completedAt|fromdateiso8601)-(.startedAt|fromdateiso8601))] | @tsv' <out>.json | sort -t$'\t' -k2 -nr
