<objective>
Deliver DX-01: a single `mix ci` command that reproduces the merge gate locally and
exits non-zero on any failure. Implemented as a real `Mix.Task`
(`Mix.Tasks.Scoria.Ci` at `lib/mix/tasks/scoria.ci.ex`) exposed via the

preflight, runs all steps then aggregates (mirroring CI's `verify-summary` fan-in),
offers ONE non-authoritative opt-out (`--skip-optional`), and documents the deliberate
local-vs-CI asymmetry in the maintainer/operator/README docs.

Purpose: a contributor runs ONE command before pushing and gets the same verdict CI
gives — fast feedback, a green that never lies.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| lane `command` string → `sh -c` | command strings are passed to a shell; shell-injection surface |
| env vars → task behavior | `SCORIA_DB_PORT`, `SCORIA_CI_SKIP_OPTIONAL` influence preflight/skip behavior |
| exit code → contributor/pre-push hook | the integrity of the verdict (false-green is the headline threat the phase exists to prevent) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-28-01 | Tampering | lane `command` strings run via `System.cmd("sh", ["-c", ...])` | accept | Command strings originate ONLY from the in-repo `Scoria.VerificationLanes` SSOT module (compile-time literals), never from user input or env interpolation. No untrusted data reaches the shell. Severity: low. |
| T-28-02 | Elevation/Integrity | the aggregate exit code (false-green) | mitigate | Run-all-aggregate then `System.halt(1)` on ANY non-zero (D-A3); pgvector-absent hard-fails non-zero (D-B1); `--skip-optional` ALWAYS exits non-zero with a `RESULT: PARTIAL ... NOT a merge-gate pass` stamp (D-B3). A green can never be produced while a gating lane was skipped. Severity: this is the core invariant. |
| T-28-03 | Tampering | `SCORIA_CI_SKIP_OPTIONAL` env opt-out | accept | The opt-out cannot manufacture a false green — it forces a non-zero PARTIAL exit. Severity: low. |
| T-28-04 | Information disclosure | `SCORIA_DB_PASSWORD=postgres` echoed in streamed lane output | accept | The password is the well-known local-dev default already committed in `verification_lanes.ex`; not a secret. Severity: none. |
| T-28-SC | Tampering | npm/pip/cargo installs | n/a | No package-manager installs in this phase (pure Elixir Mix task + docs; no new deps). |
</threat_model>
