OVERLAY DISPATCH (resolves open question #3 — chosen strategy):
  Use Playwright page.click() on the first visible row button for overlays that open on row
  click (idiomatic, avoids LiveView event synthesis). After clicking, re-await data-scoria-ready.
  Per-screen overlay manifest (verified in RESEARCH "Overlay Capture" table), hardcoded in shots.mjs:
    approvals (/approvals)  → modal:   click first button[phx-click="select_approval"] (seeded pending approval supplies a real id)
    connectors (/connectors)→ connector_drawer: click first [phx-click="open_connector_drawer"]
    connectors (/connectors)→ runtime_drawer:   click first [phx-click="open_runtime_drawer"]
    prompt_release (/prompts/:id/release) → approve_modal: click [phx-click="open_approve"] (no payload)
    live_ops, incidents, reviews, eval_specs, workflows → no overlay (baseline only)

EMPTY-STATE CAPTURE (resolves open question #1 — chosen strategy = RESEARCH option (a)):
  5 tenant-scoped screens (live_ops, approvals, connectors, incidents, workflows-via-OrchestratorLive)
  switch empty/populated via the ?tenant= query param: empty=tenant_empty flag, populated=tenant_seeded.
  4 global-list screens (reviews, eval_specs, prompts, workflows-index) do NOT read params["tenant"]
  → SKIP their empty matrix state; capture populated only. The manifest marks each screen with
  `tenantScoped: true|false`; shots.mjs only emits the empty captures for tenantScoped screens.
  This limitation must be documented in docs/MAINTAINERS.md (Plan 04).

SENTINEL + THEME + VIEWPORT (verified, assets/js/scoria.js):
  Sentinel: data-scoria-ready="true" on <html>, set on phx:page-loading-stop (line ~84).
    Gate: page.waitForFunction(() => document.documentElement.getAttribute('data-scoria-ready')==='true', {timeout:5000}).
    Call AFTER page.goto resolves; sentinel clears on navigation. Poll ~100ms, 5000ms timeout.
  Theme: ThemeToggle is CSS-only (line ~48) — set document.documentElement.setAttribute('data-theme', 'light'|'dark')
    via page.evaluate; do NOT re-await sentinel after theme toggle (no LiveView round-trip — Pitfall 1);
    a short page.waitForTimeout(100) for CSS repaint is sufficient.
  Viewport: desktop 1280×900, mobile 375×812 (UI-SPEC Implementation Notes 4).

OUTPUT LAYOUT (UI-SPEC Implementation Notes 2 / RESEARCH structure):
  priv/shots/{YYYY-MM-DD}/{screen}/{state}.png  where {state} = e.g. populated_dark_desktop,
  empty_light_mobile, modal_dark_desktop. Critique JSON: {screen}/populated_dark_desktop.json
  (the canonical critique state per D-05).

9 SCREENS (UI-SPEC §"Screens in Scope") with paths: live_ops "/", approvals "/approvals",
  workflows "/workflows", incidents "/incidents", connectors "/connectors", reviews "/reviews",
  eval_specs "/eval_specs", prompts "/prompts", prompt_release "/prompts/:id/release"
  (prompt_release: navigate to /prompts, follow the first release link, or use a maintainer-
  supplied --release-id flag; seed Plan 01 prints the seeded draft id).

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Mix task → Node (System.cmd) | CLI flags (base-url, tenant ids) cross into the Node process argv. |
| Node/Playwright → dev server | Headless browser drives the local dev server; screenshots may contain DB data. |
| Mix task → ReqLLM (critique branch) | ANTHROPIC_API_KEY + screenshot binaries cross to the vision API. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-04 | Tampering | System.cmd shell-out to node | mitigate | Arguments passed as a list to System.cmd("node", args, ...) — never interpolated into a shell string (RESEARCH Pattern 2, PATTERNS "System.cmd list-of-args safety"). OptionParser strict-validates flags. |
| T-11-02 | Information Disclosure | screenshots containing DB data + API key | mitigate | priv/shots/ is gitignored except gap_register.md (enforced in Plan 04); seed data is synthetic "Acme" only (Plan 01). ANTHROPIC_API_KEY handled by ReqLLM, never logged by the task. |
| T-11-05 | Denial of Service | hung browser / missing dev server | mitigate | waitForReady 5000ms timeout with the UI-SPEC missing-sentinel error; browser closed in a finally block; node-missing + Playwright-missing detected up front with actionable Mix.raise/exit copy. |
| T-11-SC | Tampering | npm/pip/cargo installs | mitigate | This plan installs zero Hex packages (RESEARCH Package Legitimacy Audit). Playwright is a documented maintainer prerequisite (D-02), not installed by this task — no mix.exs change, no slopcheck checkpoint required. |
</threat_model>
