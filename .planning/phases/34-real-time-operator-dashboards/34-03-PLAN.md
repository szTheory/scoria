## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| selection state -> refreshed campaign list | UI-local selection must track durable campaign ids across broadcasts |
| detail component -> target lineage links | Operator drill-ins rely on durable eval run ids from campaign detail queries |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-34-08 | Tampering | campaign selection state | mitigate | Persist only `selected_campaign_id` in assigns and always rehydrate detail from `Eval.get_campaign_dashboard_detail/2` after refresh instead of retaining stale copied maps. |
| T-34-09 | Information Disclosure | target detail rows | mitigate | Populate target rows from tenant-scoped detail queries so run links and error reasons only come from the selected tenant's durable campaign lineage. |
| T-34-10 | Spoofing | status and fallback badges | mitigate | Render exact canonical status/fallback strings from durable campaign and target truth rather than deriving them from CSS state or optimistic UI assumptions. |
</threat_model>
