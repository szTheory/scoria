## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| dashboard LiveView -> PubSub topics | Live operator surface reacts to tenant-scoped projection updates |
| dashboard components -> projection maps | UI components render operator-visible status from pre-shaped query data |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-34-05 | Information Disclosure | `/scoria` dashboard subscriptions | mitigate | Subscribe only to `tenant_id`-scoped eval topics and reuse the same tenant source already used for runtimes and approvals. |
| T-34-06 | Tampering | LiveView assigns | mitigate | Reload eval summary, campaigns, and model health from canonical query APIs on broadcast instead of applying partial, UI-local counter math. |
| T-34-07 | Spoofing | campaign primary action surface | mitigate | Keep the primary action as selection-only (`Inspect Campaign Progress`) rather than privileged mutation so the board cannot accidentally expose destructive control paths. |
</threat_model>
