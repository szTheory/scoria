<objective>
Add the confluence attribute group to `Scoria.Observe.Semconv` as a hand-written, no-passthrough fixed-key projector, registered in the closed attribute registry and pinned by the existing canary.

Purpose: GATE-04 requires ungated confluence to be *inspectable*. The gate emits its own event on all three dispositions (the tool-completed event fires only inside the live-execution success branch, so on escalate and block it never fires at all), and the span adapter carries these five keys. Without them, the two dispositions that matter would produce no trace attribute anywhere.

This plan is deliberately independent of `Scoria.Confluence`: D-08 requires `@confluence_keys` to be HAND-WRITTEN because calling into `Scoria.Confluence` from Semconv would create exactly the module edge D-03 forbids. That independence is why this plan runs in wave 1 alongside the tracer.

Output: five registered `scoria.confluence.*` keys, a projector in the shipped `trust_attributes/1` shape, and canary plus exact-match test coverage.
</objective>
