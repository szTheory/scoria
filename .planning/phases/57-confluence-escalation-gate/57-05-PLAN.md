<objective>
Wire the gate's three cross-cutting concerns into `MCP.Executor`: the atomic approval-consume that stops the resume loop, the attribution and containment resolution that decides whether this call can be paused at all, and the always-on telemetry that makes an ungated evaluation inspectable.

Purpose: plan 01 proved the escalation path; this plan makes it safe to run more than once. Without the consume, `resume_run/1` re-queues the step, the handler re-executes, the identical tool call is reached, and the gate escalates forever — the documented LangGraph interrupt footgun. Without attribution resolution, deny-by-default would refuse every tool call from a handler written against Scoria's own reference fixture. Without a denominator-carrying telemetry event, GATE-04's "emits telemetry instead of blocking" produces a number nobody can act on.

Output: a consume CAS, an attribution/containment resolver with a telemetried residual, and one always-on event carrying the confluence attribute group on all three dispositions.
</objective>
