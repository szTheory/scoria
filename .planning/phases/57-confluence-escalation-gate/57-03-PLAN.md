<objective>
Repair the Phase 55 mint-site defect that makes this entire phase inert, and give the gate a way to grade on evidence quality without weakening the taint law.

`Scoria.MCP.Executor.scan_tool_output/2` calls `Trust.scan/2` without ever setting `:incoming_tier`, so `Trust.Scan.scan/2` defaults it to the shipped fail-closed default tier and the min-wins `most_restrictive/2` pins EVERY tool output to the untrusted tier regardless of what the scanner returned. A correctly installed scanner returning a clean verdict still resolves untrusted. This was verified directly against the worktree by both the orchestrator and RESEARCH.md.

Purpose: without this fix the untrusted-content leg carries no information — every tool output lights it — so the confluence gate's grading model is meaningless and, worse, the shipped `declared: :escalate` default would give the first adopter who installs a scanner a hundred-percent pause rate. CONTEXT.md D-31 names this as a hard precondition: do not ship the enforcing default without this fix.

Output: `%Trust.Verdict{}` gains a `:scanner_tier` evidence field; `scan_tool_output/2` threads an explicit trusted incoming tier at the mint site; a regression test proves a trusted outcome is now reachable.
</objective>
