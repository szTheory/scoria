<objective>
Prove the whole confluence escalation path end-to-end on ONE tainted path, then commit the durable schema it will need.

A single tool that declares all three legs (`reads_private_data`, `sees_untrusted_content`, `can_exfiltrate`) is classified by a new root-namespace `Scoria.Confluence`, refused at `Scoria.MCP.Executor` before the tool's execution Task starts, signalled to `Scoria.Workflows.Runtime` by an `exit({:shutdown, ...})`, and landed as a resumable `waiting_for_approval` run/step/approval triple through the *existing* `Workflows.mark_waiting_for_approval/3`.

Purpose: every remaining plan in this phase composes against this path. The mechanisms all exist (RESEARCH.md: "the risk is composition/ordering, not new mechanism"), so the one genuinely unproven claim — that an `exit` from the executor's supervised Task reaches `Runtime.execute_handler/6` and produces a resumable pause — is proven first, on one path, before nine plans are built on top of it.

Output: `Scoria.Confluence` + `%Confluence.Evidence{}`, the gate insertion point in `execute/4`, the new `execute_handler/6` exit clause, the consolidated D-47 migration, and a DB-backed integration test that asserts the tool body never ran.
</objective>
