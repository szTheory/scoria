Make the dashboard shell mobile-first: below `md` (<768px) the shell collapses to a single column, the fixed 248px desktop sidebar is removed from layout, and a compact sticky mobile topbar plus an accessible off-canvas nav drawer take over navigation. The drawer renders from the existing `DashboardNav` SSOT (no second nav source), borrows the established overlay accessibility contract (scrim/Escape/focus-trap/restore), and animates with transform/opacity only.
