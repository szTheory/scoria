## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| prompt template route ID -> release workbench | Public prompt IDs select catalog records but cannot select tenant-owned evidence. |
| LiveView -> EvalRun/Approval queries | Release evidence crosses into tenant-owned data tables. |
| release action -> workflow approval context | Actor and tenant context enter write-side approval flow. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-44-06-I | Information Disclosure | ReleaseWorkbenchLive evidence queries | mitigate | Add tenant filters to EvalRun and Approval lookups. |
| T-44-06-S | Spoofing | ReleaseWorkbenchLive tenant source | mitigate | Use DashboardScope assigns only. |
| T-44-06-T | Tampering | release action actor/tenant context | mitigate | Derive actor/tenant from normalized scope, not session/default fallbacks. |
| T-44-06-E | Elevation of Privilege | prompt template ID manipulation | mitigate | Treat prompt template as catalog metadata; tenant-owned linked evidence remains tenant-filtered. |
</threat_model>
