<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| host router -> Scoria live_session | Host-provided hook and resolver options enter Scoria's embedded dashboard macro. |
| host session/assigns -> DashboardScope | Host-authenticated state becomes Scoria's dashboard tenant scope. |
| browser params -> DashboardScope | Public params are visible to the gate but cannot assert tenant authority. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-44-01-S | Spoofing | `ScoriaWeb.DashboardScope.on_mount/4` | mitigate | Resolve tenant only from default session/assigns or configured host resolver; tests prove query params are ignored. |
| T-44-01-T | Tampering | `scoria_dashboard/2` opts | mitigate | Allow only `:on_mount` and `:scope_resolver`; append Scoria hooks after host hooks and keep root layout fixed. |
| T-44-01-I | Information Disclosure | missing or malformed scope failure | mitigate | Halt/redirect before LiveView data reads and use generic UI-SPEC copy. |
| T-44-01-E | Elevation of Privilege | host hook order | mitigate | Router tests assert host auth hook runs before DashboardScope and DashboardNav remains last. |
| T-44-01-SC | Tampering | package installs | accept | No package-manager install task exists; RESEARCH.md Package Legitimacy Audit reports no external packages. |
</threat_model>
