<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser URL -> run ID | Public run IDs can be tampered with and must be authorized server-side. |
| LiveView -> Runtime/Workflows contexts | Tenant-checked dashboard code calls existing contexts that still accept raw IDs. |
| PubSub -> workflow detail | Subscription can reveal updates for a run if called before visibility checks. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-44-04-I | Information Disclosure | `WorkflowLive.Show` | mitigate | Fetch by asserted tenant and run ID before rendering or subscribing. |
| T-44-04-E | Elevation of Privilege | run ID URL tampering | mitigate | Treat route ID as selector only; validate visibility through OperatorSurface helper. |
| T-44-04-S | Spoofing | workflow index tenant source | mitigate | Read tenant from DashboardScope assigns only. |
| T-44-04-R | Repudiation | linked decision/review evidence | mitigate | Keep linked evidence tied to tenant-visible run state and existing audit rows. |
