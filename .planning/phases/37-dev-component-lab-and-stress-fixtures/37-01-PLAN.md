<objective>
Establish the dev-only Component Lab data spine and its structural safety guard: the deterministic fixture catalog (`DevLab.Fixtures`), the single lab-state to visual-tone mapping plus the reusable state-band renderer (`DevLab.Sections.States`), and the source-scan boundary/coverage test that proves the lab stays out of the public macro, out of the Hex tarball, and out of runtime `lib/` code paths.

Purpose: Everything the later section views render is keyed off this fixture catalog and state vocabulary, and every later build task verifies against this one guard test — so it lands first (Wave 1) as the Nyquist anchor for the whole phase.

Output: `dev/lab/fixtures.ex`, `dev/lab/sections/states.ex`, `test/scoria_web/dev_lab_boundary_test.exs`.
</objective>
