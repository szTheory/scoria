## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `mix test` -> provider seam | Offline tests invoke LLM-facing code that must not cross into live network behavior. |
| Maintainer refresh task -> cassette store | A mutating command writes committed replay artifacts that later CI runs will trust. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-25-04 | Denial of Service | offline runner | mitigate | Fail fast on missing fixtures instead of hanging on live network calls or implicit record attempts. |
| T-25-05 | Tampering | cassette identity | mitigate | Build cassette keys from immutable prompt/dataset/spec/provider/model inputs and persist provenance metadata with each refresh. |
| T-25-06 | Elevation of Privilege | refresh task | mitigate | Keep recording behind an explicit `mix scoria.eval.refresh` command with obvious mutating help text; never invoke it from `mix test`. |
