## Spacing Scale

All spacing resolves to `--scoria-space-N` primitives. Components bind to primitive tokens only.

| Token | Primitive | Value | Usage |
|-------|-----------|-------|-------|
| `--scoria-space-1` | xs | 4px | Icon gaps, badge dot, status rail width |
| `--scoria-space-2` | sm | 8px | Button padding block, badge padding, compact inline gaps |
| `--scoria-space-3` | md-sm | 12px | Table cell padding, nav item padding, form field gaps |
| `--scoria-space-4` | md | 16px | Panel padding, button padding inline, default element gaps |
| `--scoria-space-5` | lg | 24px | Section gaps, modal padding, page-header margin-bottom |
| `--scoria-space-6` | xl | 32px | Main content padding, major section breaks |
| `--scoria-space-7` | 2xl | 48px | Empty-state vertical padding |
| `--scoria-space-8` | 3xl | 64px | Reserved for phase-level page spacing (Phase 13+) |

Exceptions:
- Table `thead th` sticky top remains `position: sticky; top: 0` (layout, not spacing token).
- Density toggle compact mode: table cell padding reduces from `--scoria-space-3` to `--scoria-space-2` (8px) — only inside `.scoria-table--compact`.
- Density toggle comfortable mode: table cell padding increases to `--scoria-space-4` (16px) — only inside `.scoria-table--comfortable`.
- Touch targets for interactive table rows and drawer dismiss buttons: minimum 44px height enforced via `min-height: 44px`.

Source: `assets/css/02-tokens.css` §8.3 (locked).

All sizes resolve to `--scoria-fs-*` primitives. IBM Plex Sans for prose; JetBrains Mono for IDs, code, and raw evidence.

|------|-------|------|--------|-------------|-------|

## Color

All components bind to **semantic tokens only** — never raw hex, never primitive palette tokens.
Raw palette class usage (`stone-/rose-/sky-/emerald-/amber-/blue-/gray-/...`) under `lib/scoria_web/` is prohibited (DS-06 build guard).

### Surface split (60 / 30 / 10)

| Role | Semantic Token | Light Value | Dark Value | Usage |
|------|----------------|-------------|------------|-------|
| Dominant surface (60%) | `--scoria-surface-app` | `#faf5ef` | `#11100f` | Page background, shell fill |
| Secondary surface (30%) | `--scoria-surface-panel` | `#fff9f3` | `#181513` | Cards, sidebar, panels, table container |
| Raised surface | `--scoria-surface-panel-raised` | `#ffffff` | `#211c19` | Modal panels, drawer shells, table `thead` sticky bg, evidence group cards |
| Sunken surface | `--scoria-surface-sunken` | `#f1e8de` | `#0c0b0a` | Form inputs, code blocks, raw evidence `<pre>` |
| Overlay scrim | `--scoria-surface-overlay` | `rgba(24,21,19,.42)` | `rgba(8,7,6,.66)` | Drawer/modal scrim backdrop |

### Accent (10%) — reserved-for list

Accent is **`--scoria-action`** (ember-500 in dark, scoria-600 in light). It is reserved **only** for:
- Primary `.scoria-button--primary` background
- Nav item `[aria-current="page"]` left inset border
- Density toggle active-state button background
- `<.table>` sort indicator (active column ascending/descending arrow)
- Notebook panel tab underline (active tab only)
- Focus ring (`--scoria-focus-ring` = molten-400) on all interactive elements

### Semantic / tone tokens

All status coloring flows through `ScoriaWeb.UI.tone/1` → tone atom → `.scoria-badge--{tone}` class.
No component may hardcode a color for a domain status directly.

| Tone | Token family | Reserved for |
|------|-------------|--------------|
| `:pass` | `--scoria-tone-pass-*` | completed, success, approved, healthy |
| `:info` | `--scoria-tone-info-*` | running, in_progress, reference, queued |
| `:warn` | `--scoria-tone-warn-*` | pending, needs_review, approval_requested |
| `:fail` | `--scoria-tone-fail-*` | failed, error, rejected, unhealthy |
| `:trace` | `--scoria-tone-trace-*` | replay, experiment, trace, promotion_candidate |
| `:brand` | `--scoria-tone-brand-*` | selected row state, active nav, dataset selection highlight |
| `:neutral` | `--scoria-tone-neutral-*` | default/unknown state, ghost hover, tag pills |

### Destructive color

`--scoria-danger-action` (danger-dark in dark theme, danger-light in light theme) is reserved **only** for:
- `.scoria-button--danger` (border + text)
- Dismiss/delete confirmation copy
- Terminal offline reason blocks

## Component Inventory (Phase 12 deliverables)

Each component lives in `lib/scoria_web/components/ui.ex` and emits only semantic CSS class names.

### DS-01: `<.table>` — sortable, filterable, paginated data table

**CSS class:** `scoria-table` + modifiers

| Attribute | Type | Default | Contract |
|-----------|------|---------|----------|
| `rows` | list | required | Data rows to render |
| `sort_by` | atom/string | nil | Active sort column key; nil = no sort |
| `sort_dir` | atom | :asc | `:asc` or `:desc` |
| `density` | atom | :default | `:compact`, `:default`, or `:comfortable` |
| `id` | string | required | DOM id for LiveView keyed updates |

**Slots:**
- `<:col>` — one per column; required attrs: `label` (string), `key` (atom, for sort); optional: `class`
- `<:empty>` — content to render when `rows == []`; if absent, default empty state renders
- `<:action>` — action buttons column (right-aligned, no sort)

**Sort affordance:** Clicking a `<:col>` header emits `phx-click="sort"` with `phx-value-by={key}`. Sort indicator: up/down chevron SVG (16×16) inline in `<th>`, colored `--scoria-action` when active, `--scoria-text-subtle` when inactive.

**Filter/search:** The `<.table>` shell renders a slot-driven `<:filter>` region above the `<table>` element. Components that need filter controls (selects, search input) drop them into this slot. The table shell does not own filter state — the parent LiveView does.

**Search input:** Standard `<input type="search">` styled with class `scoria-input` (see DS-03 form controls). Emits `phx-debounce="200"` by default.

**Pagination:** Rendered below the table as a `<nav aria-label="Pagination">` strip. Attributes: `page` (integer), `total_pages` (integer), `on_page_change` (event name string). Shows prev/next chevron buttons + current page label. Buttons use `.scoria-button--ghost.scoria-button--sm`. Hidden when `total_pages <= 1`.

**Density toggle:** Three-button pill above the table (compact / default / comfortable). Emits `phx-click="set_density"` with `phx-value-density`. Active button uses `--scoria-action` background + `--scoria-action-fg` text (same contract as primary button). Pill border: `.scoria-border`.

**Row selection:** Clicking a row sets `aria-selected="true"` and adds `.scoria-row-selected` class (brand-bg tint). Row selection emits `phx-click` with `phx-value-id`.

**Empty state:** Renders inside `<tbody>` as a single full-width `<td>`. Uses `.scoria-empty` styles. Default copy: "No records found" / "Adjust your filters or check back when data is available."

**Density class map:**
- `:compact` → `.scoria-table--compact` → cell padding: `--scoria-space-2` (8px)
- `:default` → no modifier → cell padding: `--scoria-space-3` (12px) (existing `04-components.css`)
- `:comfortable` → `.scoria-table--comfortable` → cell padding: `--scoria-space-4` (16px)

### DS-02: `<.drawer>` and `<.modal>` — slot-based overlay shells

**Existing CSS:** `.scoria-scrim`, `.scoria-modal`, `.scoria-modal__panel`, `.scoria-drawer` already defined in `04-components.css`. Function components wrap these classes and standardize open/dismiss behavior.

#### `<.drawer>`

| Attribute | Type | Default | Contract |
|-----------|------|---------|----------|
| `id` | string | required | DOM id; used by JS hook `ShowDrawer` |
| `show` | boolean | required | Controls visibility via `phx-remove` pattern |
| `on_dismiss` | string | required | phx-click event name for dismiss |
| `title` | string | nil | Heading in drawer header slot |

**Slots:** `<:eyebrow>` (optional), `<:title>` (optional), `<:actions>` (optional), `<:inner_block>` (required)

**Open animation:** `scoria-slide` (defined in `05-motion.css`): translateX(8px) → 0, 200ms, ease-out.

**Dismiss affordances (both required):**
1. "Close" ghost button (`.scoria-button--ghost.scoria-button--sm`) in the drawer header, right-aligned. Label: "Close".
2. Scrim click: `<.scrim on_dismiss={@on_dismiss} />` rendered outside the drawer panel.

**Scrim click binding:** `phx-click={@on_dismiss}` on the `.scoria-scrim` element.

**Keyboard dismiss:** `phx-key="Escape"` on the scrim element (`phx-window-keydown={@on_dismiss} phx-key="Escape"`).

**z-index:** `--scoria-z-drawer` (40) for drawer panel; scrim uses `--scoria-z-modal` (50) — drawer sits below a modal if both are open.

#### `<.modal>`

| Attribute | Type | Default | Contract |
|-----------|------|---------|----------|
| `id` | string | required | DOM id |
| `show` | boolean | required | Controls visibility |
| `on_dismiss` | string | required | phx-click event name |
| `title` | string | nil | Heading in modal header |
| `max_width` | string | "560px" | CSS max-width; override for wide evidence modals |

**Slots:** `<:title>` (optional), `<:inner_block>` (required), `<:footer>` (optional — action buttons row)

**Open animation:** `scoria-pop` (defined in `05-motion.css`): translateY(6px) scale(0.985) → 0 scale(1), 150ms, ease-out.

**Dismiss affordances (both required):**
1. X icon button (`.scoria-button--ghost.scoria-button--sm`) in modal header top-right. `aria-label="Close"`.
2. Scrim click: same as drawer.

**Keyboard dismiss:** Same `phx-window-keydown` / `phx-key="Escape"` pattern.

**z-index:** `--scoria-z-modal` (50).

**Footer layout:** `flex justify-end gap-2`. Primary action right-most. Destructive action left-aligned with a spacer (`flex-1`) separating it from confirm actions.

### DS-03: Form control set — `<.field>` and `<.form_section>`

#### `<.field>`

Wraps a single label + input/select/textarea + optional help text + validation error display.

| Attribute | Type | Default | Contract |
|-----------|------|---------|----------|
| `id` | string | required | Forwarded to input element; label `for` matches |
| `label` | string | required | Human label text (not uppercase — title-case) |
| `help` | string | nil | Muted helper text below input |
| `error` | string | nil | Validation error string; when present renders error display |
| `required` | boolean | false | Adds `required` attr + asterisk suffix on label |

**Label:** `<label>` at 12px (`--scoria-fs-label`), weight 600, color `--scoria-text`, `margin-bottom: --scoria-space-1`. Required asterisk: `*` in `--scoria-danger-action` color, `aria-hidden="true"`.

**Input:** Class `scoria-input`. Contract:
- Background: `--scoria-surface-sunken`
- Border: `1px solid --scoria-border`; on focus: `1px solid --scoria-action`, `outline: 2px solid --scoria-focus-ring`, `outline-offset: 0`
- Border-radius: `--scoria-radius-md` (10px)
- Padding: `--scoria-space-2` block × `--scoria-space-3` inline (8px × 12px)
- Font: `--scoria-fs-body` (14px), weight 400, color `--scoria-text`
- Placeholder color: `--scoria-text-subtle`
- Error state: border color `--scoria-danger-action`; no red background

**Validation error display:** Inline below the input. Font: 12px (`--scoria-fs-label`), color `--scoria-danger-action`, `margin-top: --scoria-space-1`. Prefixed with an exclamation icon (SVG, 12×12) for a11y: never error by color alone.

**Help text:** 12px, color `--scoria-text-subtle`, `margin-top: --scoria-space-1`.

**`<:inner_block>` slot:** Caller provides the actual `<input>`, `<select>`, or `<textarea>` element into the slot. The `<.field>` wrapper does not generate the input element — it only provides the wrapping label/error/help structure. This preserves full control over `phx-change`, `phx-debounce`, and LiveView form bindings.

#### `<.form_section>`

Groups multiple `<.field>` components with a section heading.

| Attribute | Type | Default |
|-----------|------|---------|
| `title` | string | required |
| `description` | string | nil |

## Interaction Contracts

### Table sort

- Click sortable `<th>` once: sort ascending (arrow up, accent color).
- Click same `<th>` again: sort descending (arrow down, accent color).
- Click different `<th>`: reset to ascending on new column.
- Sort state is owned by the parent LiveView; `<.table>` emits `phx-click="sort" phx-value-by={key}`.
- Non-sortable columns (`:action` slot): no sort arrow, no click binding.

### Table density toggle

- Three states: Compact / Default / Comfortable.
- Default state on initial render: `:default`.
- State owned by parent LiveView via assign; toggle emits `phx-click="set_density" phx-value-density={value}`.
- Active button: `.scoria-button--primary.scoria-button--sm` (accent bg).
- Inactive buttons: `.scoria-button--ghost.scoria-button--sm`.
- The three buttons are wrapped in a `role="group" aria-label="Row density"` container.

### Drawer open/dismiss

- Open: parent sets `show={true}` assign via event handler; no JS.show needed (pure LiveView reassign).
- Dismiss via scrim click: emits parent's `on_dismiss` event.
- Dismiss via keyboard Escape: same event.
- Dismiss via Close button: same event.
- Scroll: drawer panel scrolls independently (`overflow-y: auto`); scrim does not scroll.

### Modal open/dismiss

- Same pattern as drawer.
- Focus trap: on open, focus is moved to the first focusable element inside `.scoria-modal__panel` via `phx-mounted` hook or `autofocus` attribute on the close button.
- Body scroll lock: modal open adds `overflow: hidden` to `<body>` via JS hook.

### Notebook tab switching

- Click tab: emits `on_tab_change` event with tab key. Parent LiveView updates `selected_tab` assign.
- Tabs render `aria-selected="true/false"` and `role="tab"`.
- Tab panel has `role="tabpanel"` and `aria-labelledby={tab-button-id}`.

### Skeleton loading

- Shown when parent LiveView assign is `nil` or `:loading`.
- Replace with actual content via `if/else` on the loading assign.
