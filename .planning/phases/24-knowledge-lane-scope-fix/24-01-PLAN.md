<objective>
Scope the CI knowledge verification lane to run only its 6 `:knowledge`-tagged
test files instead of re-running the entire suite, reclaiming ~22 min of CI
wall-clock with zero coverage loss and an unchanged merge bar.

Implements the three interlocking locked decisions from 24-CONTEXT.md:
- **D-01** — inject `["--only", "knowledge"]` (filter first, caller `args` appended)
  inside `scoria.test.knowledge.ex`; keep the `SCORIA_TEST_INCLUDE_KNOWLEDGE=true`
  env (still required so `test_helper.exs` does not pre-exclude `:knowledge`).
- **D-02** — env-gated `ExUnit.after_suite/1` `total > 0` guard (Layer 2) in
  `test_helper.exs` (Layer 1 — the built-in empty-`--only` fail — is armed for free by D-01).
- **D-03** — derived `knowledge_test_files/0` accessor + a new
  `knowledge_lane_contract_test.exs` asserting the sorted file set == the 6 known
  files AND each file `use Scoria.KnowledgeCase` (proves coverage preservation +
  enforces the single tag choke point).

Purpose: satisfy KNOW-01 / Phase 24 SC#1–SC#4. The CI YAML contract string and the
`VerificationLanes` command records stay byte-for-byte unchanged.

Output: 2 modified files + 1 new contract test file; scoped knowledge lane.
