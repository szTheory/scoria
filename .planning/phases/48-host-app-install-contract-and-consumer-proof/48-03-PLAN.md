## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Generated host runtime -> public Scoria API | The host must prove the public runtime surface directly rather than through repo-internal shortcuts |
| Operator route -> run identity | The operator page must render evidence for the exact run the host created, not a mismatched or synthetic record |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-48-03-01 | Spoofing | generated-host operator evidence | mitigate | Assert the rendered operator page contains the exact `run_id` returned by `Scoria.start_run/2`. |
| T-48-03-02 | Repudiation | runtime proof depth | mitigate | Keep the host proof bounded to one run/readback/evidence path and pair verification with `test/scoria/runtime_integration_test.exs` so deeper semantics are still covered elsewhere. |
| T-48-03-03 | Misconfiguration | optional-lane activation | mitigate | Exclude semantic-cache and knowledge-lane setup from the host runtime overlay and verify the default lane works without them. |
</threat_model>
