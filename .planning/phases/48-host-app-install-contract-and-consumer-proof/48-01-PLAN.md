<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Maintainer CLI -> host source files | The installer mutates host router/config/migration files that the host app trusts as source of truth |
| Installer output -> operator decision | Adopters rely on CLI output to know whether the default lane is actually installed or only partially patched |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-48-01-01 | Tampering | `lib/mix/tasks/scoria.install.ex` router patching | mitigate | Verify the browser-scope insertion point before writing and fail with manual guidance when the host layout is unsupported. |
| T-48-01-02 | Repudiation | installer success reporting | mitigate | Return structured per-target statuses and assert them in `test/mix/tasks/scoria.install_test.exs` so silent partial installs cannot masquerade as success. |
| T-48-01-03 | Spoofing | optional-lane messaging | mitigate | Print Tailwind, semantic-fast-path, and knowledge steps as explicit skip/optional lanes rather than implicit prerequisites. |
</threat_model>
