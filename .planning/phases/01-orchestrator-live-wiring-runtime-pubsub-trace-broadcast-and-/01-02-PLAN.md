## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Workflows → PubSub | Approval projections cross tenant topic to all OrchestratorLive subscribers for that tenant |
| LiveView → DOM | HITL modal renders operator-facing approval context |
| Operator → Workflows.approve/3 | Side-effecting resume path gated on explicit approval |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-06 | Information disclosure | RemoteApprovalProjection | **HIGH** | **block** | arguments_preview via Redactor only; never render raw arguments in HEEx (D-121) |
| T-01-07 | Elevation of privilege | Workflows.approve/3 | **HIGH** | **block** | not_pending guard rejects stale decisions (D-122); audit outbox preserved on success |
| T-01-08 | Tampering | HITL modal | MEDIUM | mitigate | Blocking overlay requires explicit approve/reject; dismiss does not call approve/3 (D-123) |
| T-01-09 | Repudiation | Multi-operator race | MEDIUM | mitigate | StaleEntryError → friendly flash; approval_decided broadcast syncs UI (D-122) |
| T-01-10 | Denial of service | Token coalesce | MEDIUM | mitigate | 75ms coalesce + 256 chunk cap per span (D-126) |
| T-01-11 | Spoofing | approve actor | MEDIUM | mitigate | Session actor_id passed to approve/3 attrs (existing pattern); host must set session keys (D-130 — doc in 01-03) |

**Gate:** Plans MUST NOT proceed if T-01-06 or T-01-07 mitigations are not implemented (redacted arguments_preview only; not_pending guard on approve/3).
