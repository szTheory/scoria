Simplest v2.11 approach: Telemetry sets `first_span_for_trace: true` when span has no sibling spans yet is hard — **emit trace_opened on every span stop where trace_id is present AND include a `trace_opened` flag in metadata from runtime when trace starts**. Pragmatic locked approach per RESEARCH: emit `{:trace_opened, header}` on **every** first span for trace — detect by checking if this is the first `:span, :stop` for trace_id in this BEAM node using `:ets` table `Scoria.Observe.OperatorBroadcast.TraceSeen` (insert_new on trace_id). Document in module @moduledoc.

4. `span_delta/1` (D-128): require `tenant_id`, `trace_id`, `span_id`, `chunk`; broadcast `{:trace_delta, %{trace_id: ..., span_id: ..., chunk: ...}}`; drop + debug when tenant_id missing.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Runtime → Telemetry | Span metadata may contain PII/secrets before redaction |
| Observe → PubSub | Redacted operational data fan-out to tenant topic subscribers |
| PubSub → LiveView | Tenant-scoped topic isolation is the access control boundary |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-01 | Information disclosure | OperatorBroadcast | **HIGH** | **block** | Redactor.redact/1 MUST run before span_stopped/1 (D-118); TraceProjection attributes_preview capped — never broadcast raw attributes |
| T-01-02 | Elevation of privilege | OperatorBroadcast | **HIGH** | **block** | Fail closed when tenant_id missing — no broadcast, debug log only (D-119); no `scoria:runs:all` topic |
| T-01-03 | Information disclosure | TraceProjection | MEDIUM | mitigate | attributes_preview cap; deny-list keys excluded from preview |
| T-01-04 | Denial of service | Telemetry hook | MEDIUM | mitigate | Broadcast is O(1) per span; no full snapshot on every stop (D-116 incremental deltas) |
| T-01-05 | Tampering | PubSub messages | LOW | accept | Server-side fan-out within BEAM cluster; host app secures /scoria route |

**Gate:** Plans MUST NOT proceed if T-01-01 or T-01-02 mitigations are not implemented (redact-before-broadcast ordering and tenant_id fail-closed drop).
</threat_model>
