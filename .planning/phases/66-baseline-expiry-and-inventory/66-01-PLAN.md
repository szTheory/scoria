  <action>
Create `lib/scoria/warning_baseline.ex` with `defmodule Scoria.WarningBaseline`.

Define struct `%Scoria.WarningBaseline.Row{surface: String.t(), warning_debt: String.t(), reason: String.t(), owner: String.t(), expires: Date.t() | nil, raw_line: integer()}`.

Implement `load/1` accepting `Keyword` with `:file` (default `.planning/WARNING-BASELINE.md`) and optional `:date` (`Date.t()`, default `Date.utc_today/0`).

Parser rules:
- Find line exactly matching `## Accepted Warning Debt` (trimmed).
- Collect subsequent `| ... |` table rows until a line starts with `## ` (exclusive) or EOF.
- Skip header row and separator row (`|---|`).
- Map columns: Surface | Warning Debt | Reason | Owner | Expires.
- `Expires` parses with `Date.from_iso8601!/1` on `YYYY-MM-DD`; blank Owner or blank Expires string → invalid row (not accepted).
- Do not read `## Resolved During` or any section after Accepted block ends.

Public API:
- `accepted_rows/1` — rows with non-blank owner and expires
- `invalid_rows/1` — blank owner or expires in Accepted section
- `expired_rows/1` — accepted rows where `Date.compare(date, expires) == :gt` (valid through end of expiry day; document in `@moduledoc`)

Add fixtures:
- `test/fixtures/warning_baseline/valid.md` — copy structure of production baseline with one row expiring 2099-01-01
- `test/fixtures/warning_baseline/expired.md` — one row with Expires 2020-01-01
- `test/fixtures/warning_baseline/invalid_blank_owner.md` — row with empty Owner
- `test/fixtures/warning_baseline/resolves_section_trap.md` — Accepted row valid + Resolved section containing a past ISO date that must not affect parser

Tests in `test/scoria/warning_baseline_test.exs` for each fixture with explicit `:date` option.

Create `lib/mix/tasks/scoria.warning_baseline.check.ex` as `Mix.Tasks.Scoria.WarningBaseline.Check`.

`@shortdoc "Fails when accepted warning debt rows are expired or invalid"`.

`OptionParser` flags:
- `--file` default `.planning/WARNING-BASELINE.md`
- `--date` as `YYYY-MM-DD` passed to `WarningBaseline.load(date: ...)`

Run flow:
1. `Mix.Task.run("app.start")` not required — pure file parse.
2. Load baseline; if `invalid_rows` non-empty → print table (Surface, Owner, Expires, issue=`missing owner or expiry`) → exit 1.
3. If `expired_rows` non-empty → print table (Surface, Expires, Owner, days_overdue as integer) → print exactly three remediation bullets from D-05: fix debt in code, move row to Resolved section, re-baseline with new owner+expiry+reason in same PR.
4. Else print `==> Warning baseline check passed` and exit 0.

`@moduledoc` note: expiry is UTC calendar date; row valid through end of expiry day.

Do NOT register in `VerificationLanes.closeout_order/0`.
