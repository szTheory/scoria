## Decisions Made
- **UI.status_label(nil) convergence:** pre-delegation, `UI.status_label(nil)` humanized the atom `nil` via `Atom.to_string(nil) -> "nil" -> "Nil"`. Post-delegation, `Copy.status_label(nil)` returns `"Unknown"` explicitly. Verified this input is unreachable at every render call site in the codebase (every caller passes a required field or an `x || y`-guarded value, e.g. `review_queue_live`'s `status_label(row.score_status || row.status)`). This is a curated-SSOT convergence, not a visible regression — recorded per plan instruction.
- **CTA preserved inline (not swapped):** `Copy.empty_cta(:datasets)` ("Promote a production trace to start a regression suite.") and the generic `Copy.empty_cta(_)` ("Adjust your filters or check back once new data arrives.") are both byte-different from the dataset page's current filtered-empty CTA text ("Adjust your filters or check back when data is available."). No byte-identical Copy home exists, so the CTA stays inline with an explanatory comment — an explicit owner decision per D2, not a debt item.
- **orientation/1 left unwired:** the dataset index is a sortable table with no per-row orientation-prose surface; `DatasetCopy.orientation/1` is documented (via a module-header comment) as intentionally unused on this page rather than silently orphaned. It has a real caller elsewhere (`DatasetCopyTest`'s direct exercise + potential future dataset-detail/promote surfaces), so it is not orphaned at the module level.
- **Obsolete test updated, not removed:** `ui_component_test.exs`'s "curated clauses are structurally above the retained generic fallback" test asserted source-string shape specific to the pre-refactor inline case-map. Since Task 1 intentionally deletes that shape (replacing it with a one-line delegation), this test was updated (Rule 1 — bug: test asserting removed implementation detail caused directly by this task) to assert the new delegation line and absence of the old inline clauses, while every behavioral test in that describe block (curated labels, atom input, "rejected", unknown input) continued to pass unchanged.
