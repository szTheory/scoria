| Boundary | Description |
|----------|-------------|

| Semantic entry/event rows -> operator DTO | Durable truth is projected into user-visible evidence and can leak tenant or actor scope if assembled incorrectly |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-46-01-02 | Spoofing | UI provenance | mitigate | Build semantic evidence in `Runtime.get_run_detail!/1` from durable entry/event truth, not UI-only composition. |
| T-46-01-03 | Tampering | fallback semantics | mitigate | Preserve `bypass`, `miss`, `reject`, and `hit` as distinct summary verdicts so non-hit outcomes cannot masquerade as absence. |
</threat_model>
