<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Repo examples/docs -> Git history | Committed examples and docs are read and copied by future operators; any plaintext provider key or unsafe pattern becomes durable guidance. |
| direnv -> interactive shell | `.envrc` content crosses into the long-lived local shell; resolving a real key here increases exposure time. |
| 1Password `op run` -> child process | Secret references resolve only for the wrapped critique command; this is the intended short-lived boundary. |
| Shell environment -> Docker Compose interpolation | Compose receives `ANTHROPIC_API_KEY` from the op-wrapped child environment for the profile-gated critique service. |
| Phase evidence -> repo artifacts | Security evidence is committed; it must not contain token material. |
