<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Host app to public Knowledge API | Host-supplied scope enters create/ingest/list/retrieval run APIs. |
| Public API to Repo | Scope determines which tenant-owned rows are written, deleted, listed, and audited. |
| Retriever/backend output to result persistence | Custom or backend results are untrusted until reloaded under the run tenant. |
