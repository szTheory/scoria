## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Query text/options to retrieval orchestration | Untrusted caller options determine retrieval scope, filters, and backend selection. |
| Retrieval orchestration to Pgvector | Query embeddings and filters cross into vector ranking over stored chunks. |
| External/custom retriever output to Scrypath normalization | Locator payloads can reference arbitrary chunk/source ids unless re-qualified. |
