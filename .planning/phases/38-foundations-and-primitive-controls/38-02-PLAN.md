and lock the remaining primitive invariants (copy-icon ceiling, two-tier size scale, uniform focus)
with regression guards — the "inconsistent stats", "oversized copy icons", and "density-control"
defects (Criteria 2/3/5 · DS-02/DS-03).

accessible name resolves to the raw ID text rather than a "Copy" verb). Everything else in DS-02
(uniform focus/disabled/loading, `:sm` copy icon ceiling, two-tier scale) is already correct in code
and needs a prospective regression guard, not new work (RESEARCH refinements 2/4).

Output: `signal_strip/1` and its `.scoria-signal*` CSS deleted; `aria-live` + `aria-label` added to
the copy controls; four new describe blocks in `ui_component_test.exs` guarding stat singularity,
copy-icon ceiling, copy accessible-name, and density/focus uniformity.

Depends on 38-01 because both plans edit `assets/css/04-components.css` (38-01 repoints toast/flash
rules; this plan deletes the `.scoria-signal*` block) — they must not run in the same wave.
