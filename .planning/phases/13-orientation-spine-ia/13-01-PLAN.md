| Boundary | Description |
|----------|-------------|
| component caller to HEEx | Component attrs may include IDs, labels, provenance text, and URLs from LiveView assigns. |
| browser to command UI | Palette markup is manipulated by later client hooks; server-rendered roles must remain safe and static. |

|-----------|----------|-----------|-------------|-----------------|
| T-13-01-01 | Information disclosure | `object_header/1` | mitigate | Render only caller-provided IDs and provenance strings with normal HEEx escaping; no `raw/1`; truncate display while preserving full ID only in `title` and `data-copy`. |
| T-13-01-02 | Tampering | `stub_page/1` links | mitigate | Accept explicit `tracking_url` and deep-link URLs from allowlisted stub metadata in later plans; component does not derive labels or paths from arbitrary params. |
