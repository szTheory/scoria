<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| query params to object pages | `from` is user-controlled and may include arbitrary nouns/IDs. |
| database object IDs to HTML | Run and prompt IDs render in headers and copy data attributes. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-13-05-01 | Tampering | origin parser | mitigate | Parse only `noun:id` with allowlisted nouns; ignore unknown values silently. |
| T-13-05-02 | Information disclosure | object header IDs | accept | IDs already appear on object pages; preserve HEEx escaping and avoid adding hidden extra object data. |
| T-13-05-03 | Spoofing | return chip | mitigate | Return chip text is derived from allowlisted noun plus escaped ID and is never the only navigation path back. |
| T-13-05-SC | Tampering | package supply chain | mitigate | No dependencies; uses existing LiveView and `ScoriaWeb.UI`. |
</threat_model>
