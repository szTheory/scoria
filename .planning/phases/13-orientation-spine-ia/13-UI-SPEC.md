# Phase 13 - UI Design Contract: Orientation Spine (IA)

> Visual and interaction contract for Phase 13. Generated by gsd-ui-researcher.
> This phase orients operators inside the existing Scoria dashboard. It is UI/IA only:
> no net-new backend capability families, no fake data, and no route split for Home.

Phase 13 turns the dashboard into a coherent control room: grouped navigation, a status-first
Home, object-aware breadcrumbs, a dashboard-scoped command palette, quality-loop links, and
honest reserved-name stubs.

---

## Visual Hierarchy And Focal Points

### Primary Screen: Home (`ScoriaWeb.OrchestratorLive` at `/`)

Focal point: the **needs-attention strip**, directly below the page title and identity line.
The page must read top-down:

1. Page title: **Home**
2. Identity line: "Every AI run in this app, traced. Approve tools, triage incidents, and gate prompt releases from here."
3. Needs-attention strip: only nonzero actionable cards, each one click to its screen.
4. Existing live run stream: full height, unchanged PubSub behavior.

The attention strip is an orientation device, not a metrics dashboard. It must not include
charts, sparklines, decorative gauges, or vanity trend cards.

### App Shell

Focal point: active nav state plus current page header. The sidebar carries the global IA;
page-level breadcrumbs carry object context only.

| Area | Visual Role | Contract |
|------|-------------|----------|
| Sidebar | Global orientation | Three groups in order: Operate, Improve, Configure |
| Topbar | Utility layer | Theme toggle, visible `Cmd+K`/`Ctrl+K` hint, shortcut help affordance |
| Page body | Task surface | Current view content; no nested page-section cards |
| Object header | Object orientation | Parent link, truncated object ID, copy affordance, status, provenance/origin chip |

### Command Palette

Focal point: search input at the top of an accessible dialog. Results render in three
sections when query is empty: Recent, Navigate, Actions. Empty sections are hidden after
filtering. Row chips expose shortcuts where available.

### Stubs

Focal point: screen name plus visible text badge **Soon**. The stub page must not resemble
a populated product surface. It shows what the future capability will do, what works today,
and where to track progress.

## Spacing Scale

Phase 13 uses Scoria's existing 4px-base token scale. New UI must bind to `--scoria-space-*`
tokens through semantic component classes. Do not introduce raw `px-*`, `p-*`, `m-*`, or
gap utility classes for new IA surfaces.

**Standard set for new layout decisions:** 4, 8, 16, 24, 32, 48, 64px.

| Token | Value | Usage |
|-------|-------|-------|
| `--scoria-space-1` | 4px | Icon gaps, badge dot spacing, inline ID/copy gaps |
| `--scoria-space-2` | 8px | Compact row gaps, kbd chip padding, nav badge padding |
| `--scoria-space-4` | 16px | Default card/control spacing, palette row padding |
| `--scoria-space-5` | 24px | Section gaps, object-header group spacing |
| `--scoria-space-6` | 32px | Main content padding, dialog breathing room |
| `--scoria-space-7` | 48px | Stub page vertical padding |
| `--scoria-space-8` | 64px | Major page breaks only |

### Locked Token Exceptions

`--scoria-space-3` = 12px is a pre-existing token used by nav item padding, table cell
padding, form controls, and component gaps. It may be used by existing component classes
such as `.scoria-nav`, `.scoria-button`, `.scoria-panel__header`, and `.scoria-taskcard`.
Do not introduce direct ad-hoc 12px values in Phase 13 templates.

`--scoria-space-9` = 96px remains a pre-existing ceiling token. Phase 13 should not use it
for new surfaces.

### Minimum Targets

- Palette rows, nav rows, attention cards, and stub-page primary links: minimum 44px hit area.
- Icon-only buttons: 44px minimum hit area, with visible tooltip/title and accessible label.
- Command palette max width: 640px; mobile width: viewport minus 32px.

## Typography

Phase 13 declares exactly four primary font sizes and two weights. Existing component-level
tokens outside this table are allowed only through existing CSS classes.

| Role | Token | Size | Weight | Line Height | Usage |
|------|-------|------|--------|-------------|-------|
| Page title | `--scoria-fs-title` | 24px | 600 | `--scoria-lh-tight` = 1.2 | Home, stub page, object pages |
| Panel heading | `--scoria-fs-panel` | 18px | 600 | `--scoria-lh-tight` = 1.2 | Attention cards, palette sections, object-header line groups |
| Body | `--scoria-fs-body` | 14px | 400 | `--scoria-lh-body` = 1.5 | Descriptions, result rows, page copy |
| Label / meta | `--scoria-fs-label` | 12px | 400 or 600 | 1.45 | Eyebrows, kbd hints, route aliases, timestamps |

**Declared weights:** 400 regular and 600 semibold. No third weight.

### Existing Component Exceptions

- `.scoria-badge` may continue to use `--scoria-fs-badge` (11px) through CSS only.
- `.scoria-metric__value` may continue to use `--scoria-fs-metric` (30px), but Phase 13
  attention cards should prefer compact count-plus-label treatment over oversized metrics.
- Mono IDs, trace IDs, shortcut chords, and route fragments use JetBrains Mono at the
  label/meta tier.

## Color

All Phase 13 UI binds to semantic tokens. New HEEx must not add raw Tailwind palette classes
under `lib/scoria_web/`; DS-06 remains active.

### Surface Split (60 / 30 / 10)

| Role | Semantic Token | Dark Value | Light Value | Usage |
|------|----------------|------------|-------------|-------|
| Dominant (60%) | `--scoria-surface-app` | `#11100f` | `#faf5ef` | Page background, main shell |
| Secondary (30%) | `--scoria-surface-panel` | `#181513` | `#fff9f3` | Sidebar, attention cards, palette body, stub panels |
| Raised surface | `--scoria-surface-panel-raised` | `#211c19` | `#ffffff` | Palette dialog, modal-like surfaces, object-header grouped details |
| Accent (10%) | `--scoria-action` | `#e65a32` | `#b94f31` | Reserved list below |
| Destructive | `--scoria-danger-action` | `#ff6b4a` | `#9e2f20` | Destructive actions only |

### Accent Reserved For

Accent color is reserved only for:

- Primary CTA buttons (`.scoria-button--primary`)
- Active sidebar nav marker (`.scoria-nav[aria-current="page"]`)
- Command palette selected row indicator
- Focus ring (`--scoria-focus-ring`)
- Active notebook/palette tab underline
- Active route/shortcut chip when it is the currently selected command

Accent must not be used for all links, all icons, generic body text, default nav icons,
or every interactive row. Links use `--scoria-link` only where a text link is needed.

### Status And Stub Semantics

- Status is never color-only; every badge or span includes visible text.
- Stub nav items use muted foreground plus a visible **Soon** text badge.
- Stub pages use neutral/informational tones, never fail/warn tones.
- Destructive semantic color is not used by this phase because Phase 13 introduces no
  destructive action.

## Status Home Contract

Home is a status-first screen at `/`, not a new route.

### Required Structure

| Order | Section | Contract |
|-------|---------|----------|
| 1 | Page title | `Home` |
| 2 | Identity line | Exact copy from Copywriting Contract |
| 3 | Needs-attention strip | Nonzero actionable states only |
| 4 | All-clear line | Rendered only when there are no actionable cards |
| 5 | Live run stream | Existing stream and PubSub behavior preserved |

### Attention Cards

Cards render only when actionable count is nonzero:

| Card | Trigger | Link Target | Copy Pattern |
|------|---------|-------------|--------------|
| Pending approvals | `approval_count > 0` | `/approvals` | `{N} tool calls require approval. Oldest waiting {age}.` |
| Open incidents | `incidents_summary.open > 0` | `/incidents` | `{N} incidents open. {M} paging.` |
| Degraded connectors | `fleet_summary.connectors_degraded > 0` | `/connectors` | `{N} connectors degraded. View connector health.` |
| Review queue / failing gates | Cheap count available | `/reviews` or `/eval_specs` | `{N} review items need triage.` or `{N} eval gates failing.` |

All-clear copy: "Nothing needs attention. 0 approvals pending, 0 open incidents."

Day-0 empty stream copy: "No traces yet. Run your first chat response or MCP request to see the run tree."

No charts, sparklines, trend lines, map widgets, or synthetic status data.

## Command Palette And Shortcut Contract

The command palette is a dashboard-scoped vanilla JS hook. Server renders the full command
list into the DOM at mount; the hook filters locally.

### Palette Behavior

| Behavior | Contract |
|----------|----------|
| Open | `Cmd+K` on macOS, `Ctrl+K` elsewhere |
| Close | Escape, scrim click, or selecting a command |
| Typing | Case-insensitive substring filter over label and aliases |
| Sections | Recent (max 5), Navigate, Actions |
| Empty result | Exact copy from Copywriting Contract |
| Motion | Opacity-only, <=200ms, disabled under `prefers-reduced-motion` |
| Scope | Dashboard layout only; hook removes listeners on destroy |

Keyboard handling:

- Ignore events from `input`, `textarea`, `select`, `button`, `[contenteditable]`, and IME
  composition (`event.isComposing`).
- Prevent default only for owned keys.
- No socket traffic while typing.
- No fuzzy-search library.

### Chord Map

| Chord | Destination |
|-------|-------------|
| `g h` | Home |
| `g a` | Approvals |
| `g r` | Runs |
| `g i` | Incidents |
| `g c` | Connectors |
| `g q` | Review Queue |
| `g e` | Eval Workbench |
| `g p` | Prompt Registry |

Chord timeout: 1.5s. No global approve/deny/escalate shortcuts in v1.

### Accessibility

- Palette container: `role="dialog"`, `aria-modal="true"`, labelled by visible heading.
- Results: `role="listbox"` with `aria-activedescendant`.
- Rows: `role="option"`, keyboard selected row reflected via ARIA and visual selected state.
- Focus moves to search input on open and returns to invoker on close.
- Visible `Cmd+K`/`Ctrl+K` hint in the topbar and `?` shortcut overlay are required.

## Object Header And Threading Contract

Add `ScoriaWeb.UI.object_header/1`. Index screens do not render breadcrumbs; object screens do.

### Object Header Structure

| Line | Content |
|------|---------|
| 1 | Breadcrumb: `{Parent screen, linked} / {object id, plain}` |
| 2 | Identity row: type badge, mono ID with copy, status badge, key scalar |
| 3 | Optional provenance line and/or origin return chip |

ID display: middle-truncate long IDs, expose full ID in `title`, and use the existing `CopyId`
hook through `ScoriaWeb.UI.id/1`.

Origin context:

- Query param shape: `?from={noun}:{id}`.
- Allowlisted nouns only; unknown values are ignored silently.
- Return chip copy: `← Back to {noun} {id}`. Locked D-21 example: `← Back to incident inc_42`.
- The chip is never the only way back.

### Quality-Loop Link Verbs

No persistent stepper. Threading is a consistent next-step verb cluster.

| Surface | Required Verb Links |
|---------|---------------------|
| Incident | Open run; Open trace at failing span |
| Run show | Replay run; Promote span to dataset; Open incident if linked; Open prompt |
| Review item | Open run; Promote to dataset |
| Dataset row | Open source run |
| Eval result | Open prompt release; Open regressed runs |
| Release Workbench | View eval results; View baseline runs |

Provenance grammar:

`{Verb-ed} from {noun} {id} via {noun} {id} - {date}`

Example:

`Promoted from run trc_01J8KQ... via review rev_204 - Jun 9`

## Stub Page Contract

Five reserved capabilities appear in the IA as honest coming-soon screens:

- Replay Playground
- Cost Ledger
- Feedback Inbox
- MCP Gateway
- Tool Registry

Stub route: `/coming/:screen`, backed by one shared allowlisted LiveView.

### Stub Anatomy

| Order | Element | Contract |
|-------|---------|----------|
| 1 | Screen name + badge | Visible text badge: `Soon` |
| 2 | One-sentence future capability | Evidence verbs only; no hype |
| 3 | "What works today" | Existing paths with deep links |
| 4 | Tracking link | Use a real issue URL, a repository issue-search URL, or omit numeric ID; never fabricate issue numbers |

Forbidden:

- Mock charts
- Placeholder rows
- Skeleton screens
- Fake counts
- Fake screenshots
- Capability claims in present tense

Stub sentence grammar:

`{Name} will {evidence verb} {object} so operators can {governance outcome}.`

Example:

`Replay Playground will compare replay branches against source runs so operators can inspect changed evidence before promotion.`

## Interaction Contracts

### Sidebar

- Group labels are non-interactive.
- Active nav item uses `aria-current="page"`.
- Soon items are real links with a visible `Soon` badge; disabled-looking style must not
  remove clickability.
- Sidebar remains usable under embedded mount prefixes through `@scoria_base`.

### Topbar

- Keep Theme toggle.
- Add command palette button with visible kbd hint.
- Remove the global fake breadcrumb pattern from object orientation; object breadcrumbs
  live in page-level `object_header/1`.

### Palette

- ArrowUp/ArrowDown move active result.
- Enter activates selected result.
- Escape closes and restores focus.
- Typing filters without LiveView events.
- Recent objects persist in localStorage key `scoria:recents:<mount-base>`, cap 8 stored
  and 5 shown.

### Object Pages

- Parent breadcrumb is the only clickable breadcrumb segment.
- Object ID is plain text plus a copy affordance.
- Status is a text badge.
- Origin chip is dismissible and secondary to normal nav.

### Motion

- Palette open/close: opacity only, <=200ms.
- Selected-row hover/active: background/color only, <=100ms.
- No fire/sparkle/bounce metaphors, no infinite loops, no layout-property animation.
- Respect `prefers-reduced-motion`.
