<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| incident/review records to links | Stored IDs become URL path and query parameters. |
| operator browser to navigation | Links navigate across dashboard screens with contextual `from` params. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-13-07-01 | Tampering | link construction | mitigate | URL-encode query values or construct with URI helpers; use existing IDs only; no user-entered path fragments. |
| T-13-07-02 | Information disclosure | context query params | accept | Incident/review IDs already appear on their source pages; destination object header allowlists and escapes `from` values in Plan 13-05. |
| T-13-07-03 | Repudiation | verb links | accept | Links do not mutate state; promotion remains behind existing explicit action flow. |
| T-13-07-SC | Tampering | package supply chain | mitigate | No packages or external services. |
</threat_model>
