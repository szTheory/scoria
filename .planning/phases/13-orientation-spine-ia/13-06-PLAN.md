<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser keyboard to dashboard navigation | Global keydown listeners can affect host app behavior if not scoped and cleaned up. |
| localStorage to palette UI | Recent objects are browser-local and user-controlled. |
| command rows to navigation | Command activation changes `window.location` to dashboard paths. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-13-06-01 | Elevation of privilege | command actions | mitigate | Palette commands include navigation plus `Toggle theme`, `Keyboard shortcuts`, and `Copy current page URL` only; no approve, deny, release, promote, delete, or destructive command. |
| T-13-06-02 | Denial of service | global key listeners | mitigate | Bind listeners in `mounted`, remove in `destroyed`, ignore editable targets and IME composition, and preventDefault only for owned keys. |
| T-13-06-03 | Information disclosure | localStorage recents | mitigate | Store only object label, path, kind, and ID that are already visible on object pages; cap at 8; no server persistence. |
| T-13-06-04 | Tampering | command destinations | mitigate | Navigate rows are derived from allowlisted `DashboardNav.groups/0`; no arbitrary command path is read from user input. |
| T-13-06-SC | Tampering | package supply chain | mitigate | No npm package or registry component may be added; `node --check` validates existing plain JS only. |
</threat_model>
