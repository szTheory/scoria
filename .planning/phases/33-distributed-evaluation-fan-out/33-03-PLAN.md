<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Oban job envelope -> worker execution | Asynchronous job payload becomes real model execution and durable result writes |
| worker result -> campaign aggregate row | Child execution outcomes are summarized into cheap-to-read parent counters and terminal status |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-33-07 | Spoofing | job envelope tenant identity | mitigate | Require worker args to include explicit `tenant_id` for inspectability, but resolve execution identity from persisted campaign/target/run lineage and reject mismatched envelope tenants. |
| T-33-08 | Repudiation | campaign rollup counters | mitigate | Make worker finalization idempotent and derive each counter mutation from persisted target state transitions so retries cannot silently double-count completions or failures. |
| T-33-09 | Denial of Service | failure handling | mitigate | Keep retries bounded and classify only the explicit fatal classes as campaign-aborting; all other worker failures stay shard-local and resolve to `completed_partial` instead of cascading cancellation. |
</threat_model>
