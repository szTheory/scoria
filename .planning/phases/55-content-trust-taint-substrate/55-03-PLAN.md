<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| untrusted content → assembled prompt | the model must be able to distinguish instructions from untrusted data |
| attacker content → marking boundary | attacker content may contain the literal marker to "close" the untrusted span early |
| render internals → telemetry/logs | the nonce and raw content must never escape into observability |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-55-10 | Tampering / Elevation of Privilege | prompt injection via untrusted content (OWASP LLM01) | high | mitigate | Datamark/delimit signal-separation (D-12); documented as a separator, not a full defense (real containment = Phase 57). |
| T-55-11 | Tampering | closing-delimiter injection | high | mitigate | Per-call random nonce (`strong_rand_bytes(16)`), verified absent from content, bounded retries then `:delimit` fallback (D-12). Collision-fixture test. |
| T-55-12 | Information Disclosure | nonce/content leakage via telemetry | high | mitigate | `[:scoria, :spotlight, :marked]` carries counts/enums only, `try/rescue -> :ok`; registry admits only the closed `scoria.spotlight.*` enum/count keys (D-14). Payload-absence test. |
| T-55-13 | Elevation of Privilege | Scoria owning prompt content | medium | mitigate | Instruction returned as overridable data, never injected; host places it (D-13). |
| T-55-14 | Tampering | host self-concatenation bypass | medium | accept | Documented residual (D-15); docs-only mitigation this phase, `SECURITY-BOUNDARY.md` in Phase 58. |
</threat_model>
