<objective>
Land TAINT-02: tool outputs are wrapped in `Scoria.MCP.Envelope` carrying a trust tier so downstream code treats them as potentially-untrusted rather than implicitly-trusted context. Taint is always computed and persisted (inspectable); the return-shape change is soft-launched behind a default-off flag so no adopter is bricked (D-08, the v3.4 `ReleaseGate` precedent).

Purpose: The envelope is the tool-output leg of the taint substrate the Phase 57 confluence gate reads. Total accessors (D-09) make it flag-agnostic; replay-stub parity (D-10) prevents a correctness divergence for consumers written against `{:ok, %Envelope{}}`.

Output: `Scoria.MCP.Envelope` struct + total accessors + `Trust.Tiered` impl, wrapping wired at the executor success choke point and the replay-stub path, with an `actual_units` defense-in-depth head.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| tool output → downstream context | tool results are untrusted content, not implicitly-trusted context |
| replay stub → consumer | a replay result must not diverge in shape from a live result |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|

| T-55-06 | Tampering | double-nested envelope value | medium | mitigate | Wrap only the `{:ok, value}` inner value, never the tagged tuple (D-07); regression test asserts `Envelope.value == raw` (Pitfall 1). |
