<objective>
Complete TAINT-04 by wiring the Plan 04 scan engine into the two taint-MINTING chokepoints and tagging the existing spans with a fixed `scoria.trust.*` projector — the sharpest red-team fix (D-18): a host that assembles its own prompt would never call `Spotlight.render`, so anchoring scan only there would make the seam decorative. Scan fires where Scoria mints untrusted content and controls the seam: batch-scan at `Knowledge.retrieve/2` (tagging its RETRIEVER span) and scan at `MCP.Executor` envelope creation (tagging the tool span and populating `Envelope.scan`).

Purpose: This closes the loop so a host with a registered scanner sees scanned/untrusted content tagged in traces, and a host with none sees byte-identical current behavior. The `scoria.trust.*` projector mirrors `guardrail_attributes/1`'s leak-immunity (counts/enums/ids only, no `score`), and — per D-22, recorded for Phase 57 — the `reason_code` distinguishes content-untrusted from infra-failure-untrusted.

Output: `Semconv.trust_attributes/1` + registry keys, scan wired at `retrieve/2` and the executor, and the `Envelope.scan` slot populated.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| minted untrusted content → trace | scan verdicts must tag traces without leaking content or scores |
| scan verdict → envelope tier | a verdict may only add taint to the tool-output envelope |
| unscanned content → false confidence | with no scanner, behavior must be unchanged (no false "scanned" signal) |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-55-20 | Information Disclosure | `score`/free-text leaking to a span or jsonb | high | mitigate | `trust_attributes/1` projects only 4 declared keys (no `score`); registry admits only closed enum/id/count classes; score-absence tests (D-21). |
| T-55-21 | Tampering | scan tag routed through `Guardrail.emit/1` (mislabels classification as decision) | medium | mitigate | Tags attach to existing spans via the fixed projector, never `Guardrail.emit/1` (D-21). |
| T-55-22 | Elevation of Privilege | envelope trust upgraded by a scanner | high | mitigate | Envelope tier resolved via the monotonic law over the default untrusted — scanner can only add taint (D-19/D-18). |
| T-55-23 | Denial of Service | scan overhead when no scanner is registered | medium | mitigate | NoOp short-circuits at both call sites; byte-identical-behavior tests (D-17). |
