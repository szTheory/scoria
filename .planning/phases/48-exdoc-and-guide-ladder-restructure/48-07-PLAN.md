| Boundary | Description |
|----------|-------------|
| Mix config -> generated HexDocs | ExDoc config determines public docs IA, source links, and visible module contracts. |
| Mix package files -> Hex tarball | Package allow-list determines what adopters receive. |
| Environment -> source_ref | `SCORIA_DOCS_SOURCE_REF` is maintainer-controlled build metadata. |

| T-48-07-I | Information Disclosure | `package/0` files and ExDoc extras | mitigate | Explicit guide/stub/brand allow-list and dev-doc exclusion assertions. |
| T-48-07-S | Spoofing | ExDoc redirects | mitigate | Exact old-ID to new-ID redirect map in `docs_redirects/0` and tests. |

| T-48-07-SC | Tampering | package installs | accept | Existing dependency set only; no package manager task. |
</threat_model>
