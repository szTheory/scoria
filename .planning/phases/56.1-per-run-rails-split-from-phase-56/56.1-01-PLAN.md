<objective>
Prove the whole per-run-rails architecture end-to-end on one rail, then make the halt genuinely
terminal.

Task 1 is the tracer: a run carrying `rail_max_steps: 1` executes exactly one step, the second
admission is denied by an atomic compare-and-swap on the run row, and the run transitions to the new
terminal `"halted"` status with an audit-outbox row written inside the same transaction. That single
path touches every layer this phase modifies — migration, `Run` schema, the CAS admission module,
`Workflows.halt_run/3`, and the `Runtime.execute_step/2` enforcement site.

Task 2 closes the six resurrection paths (G1-G6) that would otherwise let an in-flight sibling walk a
halted run back to a live status.

Purpose: RAIL-01 success criteria #1 (halt is audited) and #2 (halt is terminal).
Output: the migration, `Scoria.Workflows.Rails`, `Workflows.halt_run/3`, six guards, and their tests.
