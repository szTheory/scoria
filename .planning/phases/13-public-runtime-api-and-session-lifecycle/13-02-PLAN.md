## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| host app lifecycle input → `Scoria.Runtime.Params` | Untrusted public API input is normalized into canonical lifecycle arguments |
| `Scoria.Runtime` → workflow create/resume substrate | Public lifecycle verbs trigger durable state transitions |
| host app stored `run_id` / `session_id` → public resume path | Host-owned continuity data is fed back into resume decisions |
