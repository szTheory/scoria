<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| workflow run schema → public DTO projection | Internal persistence shape is translated into stable public contracts |
| public inspect/list API → host app polling or linking code | Host apps consume returned ids and status to continue runtime flows |
| public session grouping API → continuity decisions | Grouping data may inform UI but must not become resume truth |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-13-03-01 | S | `lib/scoria/runtime.ex` | mitigate | Build inspect results from persisted workflow truth and not from caller-supplied transient maps. |
| T-13-03-02 | T | `lib/scoria/runtime/run_summary.ex` | mitigate | Freeze the public DTO field set in tests so later schema changes cannot silently mutate the host-app contract. |
| T-13-03-03 | R | `test/scoria/runtime_view_test.exs` | mitigate | Assert stable exposure of run ids, session ids, and approval-wait state so operator and host-app references remain attributable. |
| T-13-03-04 | I | `lib/scoria/runtime/run_detail.ex` | mitigate | Expose only curated fields and never return `%Scoria.Workflows.Run{}` or raw preload trees from public inspect APIs. |
| T-13-03-05 | D | `lib/scoria/runtime.ex` | mitigate | Reuse existing workflow query seams and avoid broad preloads on the default summary path. |
| T-13-03-06 | E | `lib/scoria/runtime.ex` | mitigate | Keep `session_id` helpers read-only and grouping-only so callers cannot gain resume authority without exact `run_id`. |
