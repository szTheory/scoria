<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Runtime lookup attrs -> semantic cache query | Tenant, actor, prompt, and source facts from untrusted runtime inputs become cache-selection filters |
| Semantic cache entry -> reusable answer payload | A durable answer may be returned only if compatibility proof is still valid |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-45-01-01 | Spoofing | tenant and actor scope filters | mitigate | Keep `tenant_id` mandatory, apply actor narrowing only for `actor_scoped` entries, and emit `scope_mismatch` rejects instead of widening reuse. |
| T-45-01-02 | Tampering | policy/source compatibility truth | mitigate | Persist `policy_fingerprint` and durable `source_fingerprint`, then compare those exact fields before any hit result is allowed. |
| T-45-01-03 | Information Disclosure | semantic fallback candidate search | mitigate | Run semantic ranking only after tenant/lane/scope/status/prompt/policy/source filters shrink the candidate set, per D-01 through D-05. |
| T-45-01-04 | Tampering | state truth for stale vs invalidated | mitigate | Persist `state_reason_code` and a dedicated `stale` status so age-based decay cannot be hidden inside `:miss`. |
</threat_model>
