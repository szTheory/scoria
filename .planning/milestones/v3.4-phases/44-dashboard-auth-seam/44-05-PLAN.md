<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| URL facets/deep links -> quality/data LiveViews | Public filters and IDs select review/eval/dataset UI state. |
| LiveView -> Eval context | Dashboard requests tenant-owned review/eval evidence through context functions. |
| tenantless catalog -> tenant-owned evidence | Global metadata surfaces can accidentally include tenant-owned linked rows. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-44-05-I | Information Disclosure | Review Queue | mitigate | Add tenant-specific Eval helpers and use asserted scope. |
| T-44-05-I2 | Information Disclosure | Eval Workbench | mitigate | Filter EvalRun evidence by asserted tenant. |
| T-44-05-E | Elevation of Privilege | Dataset promotion params | mitigate | Treat review/run IDs as hints and reload under asserted tenant before rendering evidence. |
| T-44-05-T | Tampering | URL facet filters | mitigate | Keep existing closed facet validation and combine with tenant helper filters. |
