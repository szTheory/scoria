<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser-to-approval events | Approve, reject, dismiss, select, and confirmation events carry user-controlled action intent. |
| Approvals LiveView to Workflows context | Approval decisions mutate durable workflow state and may resume a run. |
| browser-to-connector drawer events | Runtime and connector IDs select detail projections. |
| connector/runtime data rendering | Runtime and connector detail values may contain host-provided data. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-15-04-01 | Tampering | approval confirmation | mitigate | Keep final approve/reject behind shared modal confirmation and preserve `Workflows.approve/3` plus existing stale decision handling. |
| T-15-04-02 | Repudiation | approval/rejection consequence | mitigate | Preserve durable audit events and explicit copy distinguishing approval resume from rejection paused state. |
| T-15-04-03 | Spoofing | connector/runtime selection | mitigate | Select only from current `@runtimes` list or `OperatorSurface.connector_drawer/1`; do not add freeform detail routes. |
| T-15-04-04 | Information Disclosure | rendered connector/runtime data | mitigate | Render detail values through HEEx and shared evidence rows; do not introduce `raw/1`. |
| T-15-04-SC | Tampering | package installs | accept | No package-manager install tasks exist. |
</threat_model>
