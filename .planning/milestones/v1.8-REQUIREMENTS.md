# Vanguard (v1.8) Requirements

**Status:** Archived after ship on 2026-05-22
**Last updated:** 2026-05-22
**Archive note:** This is the shipped requirement ledger for `v1.8 Vanguard`. The historical pre-reconciliation audit snapshot remains `.planning/v1.8-MILESTONE-AUDIT.md`.

## Core Value
The Vanguard milestone introduces highly resilient multi-model orchestration and robust distributed evaluation execution. It establishes the primitives required for scale: circuit breaking, dynamic model fallback, and massive fan-out of evaluations via Oban, all while strictly adhering to the "operator-visible" and Phoenix-first mandates.

## Scope Rules
- **IN SCOPE:** Node-local ETS circuit breakers, explicit Req retry steps, Oban queue segregation, batch job insertion, LiveView progress dashboards.
- **OUT OF SCOPE (v2/Deferred):** Tenant-aware rate shaping, external eval services (LangSmith, etc.), Complex DAGs/LangGraph, cluster-aware (Phoenix.PubSub broadcast) circuit breakers, telemetry-driven p95 latency rerouting.
- **CONSTRAINTS:** No Ash framework, rely on standard Elixir OTP primitives (ETS/GenServer), Ecto, and Oban.

## Requirements

### Orchestration & Resiliency (ORCH)
- **ORCH-01:** Model Fallback Routing (Support static fallback chains across LLM providers).
- **ORCH-02:** Circuit Breakers (Track rolling failure rates and latencies of models using ETS, trip when unhealthy).
- **ORCH-03:** Configurable Retry Policies (Handle HTTP 429s gracefully with jittered exponential backoff using `Req` steps).

### Distributed Evaluation (EVAL)
- **EVAL-01:** Oban Queue Segregation (Separate queues for `inference`, `evals`, and `system`).
- **EVAL-02:** Distributed Eval Coordinator (Schedule large-scale evaluation campaigns).
- **EVAL-03:** Scalable Evaluation Insertion (Use `Oban.insert_all` to batch queue jobs and prevent DB contention).

### Observability (OBS)
- **OBS-01:** Live Eval Progress Matrix (Real-time LiveView dashboard streaming Oban job completions).
- **OBS-02:** Circuit Breaker State Visibility (LiveView visibility into the ETS-backed model health state).
