## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| package inventory -> Hex consumers | Root docs included in `mix.exs` package files become part of the published tarball. |
| docs source -> ExDoc generated output | `mix docs` reads source docs and writes ignored `doc/` artifacts, including generated `doc/llms.txt`. |
| CI workflow -> Mix task | Existing CI invokes `MIX_ENV=dev mix scoria.release_preview`; the task owns docs warning failure semantics. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-49-02-T | Tampering | `mix.exs`, release-preview inventory | mitigate | Triple-lock `llms.txt` and `AGENTS.md` in package files, required preview paths, and package/release-preview tests; explicitly exclude `GEMINI.md`. |
| T-49-02-R | Repudiation | `mix scoria.release_preview` | mitigate | Export and test `docs_task_args/0`; run docs with `--warnings-as-errors`; verify with `MIX_ENV=dev mix scoria.release_preview`. |
| T-49-02-I | Information Disclosure | ExDoc public module surface | mitigate | Keep `docs_public_modules/0` positive allowlist unchanged for contract/helper modules; use targeted ExDoc warning-skip configuration instead of making internals public. |
| T-49-02-D | Denial of Service | docs generation in release preview | accept | Docs generation may fail the release gate when warnings exist; this is intentional release-blocking behavior for DOCS-04. |
| T-49-02-S | Spoofing | maintainer docs | mitigate | Docs state release preview is canonical proof and raw docs WAE is diagnostic only, preventing a false CI proof path. |
| T-49-02-SC | Tampering | package installs | accept | No npm, pip, cargo, Hex dependency, or other package-manager install task is introduced by this plan. |
</threat_model>
