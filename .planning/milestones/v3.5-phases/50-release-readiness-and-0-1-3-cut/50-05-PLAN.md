Close Bucket G — the single highest-leverage CI blocker. All 14 identical failures raise
`(ArgumentError) the hook {ScoriaWeb.DashboardScope, :default} for lifecycle event :mount attempted to halt without redirecting`.
Phoenix LiveView 1.1.30 (bumped in the v3.5 milestone) now hard-raises when a `:mount` hook
halts without redirecting; `lib/scoria_web/dashboard_scope.ex:144-145` returns
`{:halt, put_unavailable_flash(socket)}` (a bare halt, no redirect) on
`{:error, :unauthorized | :missing_scope}`. The affected tests assert the dashboard pages
RENDER, but their shared `test_conn/0` seeds an EMPTY session (`init_test_session(%{})`), so the
`:default` resolver returns `:missing_scope` and the bare-halt branch crashes.

Purpose: one coherent fix turns all 14 red tests green and closes the LiveView 1.1.30 fail-closed
regression, unblocking the REL-04 release train. This is Phase 46-49 verification debt exposed by
the release push, NOT a Phase 50 regression.
Output: DashboardScope fails closed via redirect (never a bare halt), and the three affected test
files pass.

Do NOT weaken the fail-closed contract (D-18): DashboardScope must still refuse to render a
dashboard when no trusted tenant scope is asserted. Redirecting on missing scope IS failing
closed; opening the page without scope is NOT an acceptable fix.
</objective>
