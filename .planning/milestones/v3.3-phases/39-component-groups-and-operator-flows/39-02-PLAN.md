<objective>
Build the strings-only copy layer (Area 5 foundation, D-24b/c): a narrow `ScoriaWeb.Copy` that owns
the canonical action-verb set, status-label map, and empty/error/loading strings, plus per-domain
copy modules (`IncidentCopy`, `DatasetCopy`, `ReviewCopy`, `ConnectorCopy`) for the domains whose copy
branches on record data — all templated on the existing `ApprovalCopy` discipline.

the microcopy offender fixes (Area 5, Plans 04/05). They are pure data (no `~H`), so `UI.empty_state/1`
/ `skeleton/1` remain the renderers. Creating the modules is foundation; wiring them into pages is
Plans 04/05.

Output: five new copy modules under `lib/scoria_web/`, with unit coverage. All-new files — zero
overlap with any other Wave 1 plan.
</objective>
