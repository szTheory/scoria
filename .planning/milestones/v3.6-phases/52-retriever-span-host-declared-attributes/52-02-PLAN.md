<objective>
Add the optional `model_name/0` callback to the `Scoria.Knowledge.Embedder` behaviour and implement it on `Embedder.Deterministic`, so the RETR-02 `embedding_model` config value has a truthful in-app origin without ever risking `UndefinedFunctionError` on a host embedder that does not implement it (D-RETR02-5).

Purpose: `embedding_model` must never assert a model name Scoria did not produce; the guarded optional callback lets `retrieve/2` (52-04) read a real name when available and fall through to `"none"` otherwise.
Output: `@callback model_name/0` + `@optional_callbacks` on the behaviour; `Deterministic.model_name/0` returning a stable literal; a unit test proving both the literal and the guarded fall-through.
