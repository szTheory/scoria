<objective>
Turn the span pipeline ON. Today `Scoria.Observe.Buffer` is absent from `Scoria.Application`'s children (`lib/scoria/application.ex:10-21`) and `Scoria.Observe.Telemetry.attach/1` has zero `lib/` callers — so every span Phases 51 and 52 emit fires into a void in a real host app (D-00a). This plan wires both, with an explicit `enabled: false` opt-out.

Purpose: Phase 53 success criterion #2, and the hard prerequisite for every other plan in this phase — no other plan's acceptance criterion is verifiable against a real host pipeline until this lands.
Output: `Scoria.Observe.Buffer` supervised under `Scoria.Supervisor`; `Telemetry.attach/1` called on boot; `test/scoria/application_test.exs` proving both.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| host app process -> `:telemetry` handler | Untrusted host-supplied span metadata enters the Scoria pipeline here. Before this plan, that boundary was never crossed in production (the handler was unattached). |
| `Telemetry.handle_event/4` -> Postgres (`Buffer`) | Attribute payloads become durable, multi-tenant-readable rows. |
