<objective>
Close the pre-existing silent FK gap (FOUND-01): make `Buffer.flush_spans/1` upsert the trace row(s) before inserting spans in one `Ecto.Multi`, and replace the silent `rescue` with structured, non-fatal-but-LOUD surfacing (`Logger.error` + a new `[:scoria,:observe,:buffer,:flush_error]` telemetry event via a `Telemetry.emit_flush_error/1` wrapper). Add the `:on_flush_error` knob, a `:flush_now` synchronous test hook, a `terminate/2` raise-gate, and error-storm control.

Purpose: Every span Scoria emits has been silently failing its insert since 0.1.0 because nothing ever inserted the parent `ai_traces` row (`ai_spans.trace_id` is `null:false`) and the failure was swallowed by a bare `rescue`. This is the bug that gates the entire milestone — nothing downstream persists until it lands.

Output: fixed Buffer + Telemetry wrapper + extended buffer test proving real-Postgres persistence and loud failure surfacing.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Buffer flush -> Postgres (Repo.transaction) | insert_all bypasses changeset validation; raw Postgrex constraint errors can surface as exceptions |
| Buffer flush_error emit -> host-attached telemetry handler | Host handler runs synchronously in the Buffer GenServer process |
| flush_error Logger.error / telemetry metadata -> logs/alerting | Structured payload must not carry raw span attribute values (may contain prompt content) |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-51-02 | Denial of Service | Buffer flush error-storm logging | high | mitigate | Consecutive-failure counter (D-09 ii): log full detail once per failure run, reset on success; ALWAYS emit the telemetry event so a repeated-failure loop cannot flood logs while keeping alerting accurate |
| T-51-01 | Denial of Service | Buffer flush_error `:telemetry.execute` -> host handler | high | mitigate | Defensively wrap the emit (D-09 iv) so a raising/re-entrant host handler cannot crash or re-enter the flush path |
| T-51-04 | Denial of Service | Buffer GenServer crash-loop from uncaught Postgrex exception (Pitfall 3) | high | mitigate | try/rescue around Repo.transaction(multi) IN ADDITION to {:error,...} matching; terminate/2 never re-raises (D-09 i) — never destabilize the host (D-05) |
| T-51-03 | Information Disclosure | flush_error Logger.error / telemetry metadata | medium | mitigate | Emit counts + error struct + buffer identity only; never include raw span `entries`/`attributes` (which may carry prompt content) in the log line or event metadata |
| T-51-SC | Tampering | package installs | n/a | accept | No package installs (mix.exs unchanged) |
</threat_model>
