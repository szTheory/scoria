<objective>
Make CI compile deps + app exactly once per run and have every downstream job reuse that
compiled artifact, with cache keys that can never collide across MIX_ENV or stale tool
versions — while keeping the byte-order lane-contract tests green.

This plan delivers BOTH phase requirements together because all three change-units touch the
same two files (`ci-verify.yml`, `ci_policy_contract_test.exs`) and the repo treats the CI YAML
as a typed byte-order contract: any topology change MUST land in the same task as the
contract-test assertion that pins it. Parallelization is impossible here (shared file
ownership), so the tasks run sequentially in one wave.

Purpose: cut CI wall-clock by eliminating per-job cold compiles (CACHE-02) and stop
dev/test `_build` caches from colliding and triggering spurious recompiles (CACHE-01).

Output: modified `ci-verify.yml` (policy -> build -> test), modified `ci.yml` (e2e dev cache
key + version-file), extended `ci_policy_contract_test.exs`, and a captured no-recompile proof.
</objective>
