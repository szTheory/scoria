## Interaction Contract

| Surface | Contract |
|---------|----------|
| Proof command callout | Present one canonical command block for runtime-to-handoff proof: `mix test.runtime_to_handoff`. |
| Default lane distinction | Keep `mix test.adoption` visible as the default-lane verifier and visually separate it from runtime-to-handoff escalation proof. |
| Prerequisite truth panel | Include an explicit "Not required" list covering semantic fast-path, knowledge/pgvector setup, retrieval setup, and hosted onboarding for this lane. |
| Operator verification flow | Keep guidance ordered as: default lane proof, runtime-to-handoff proof, then closeout chain context. |
| Failure affordance | On command failure, show bounded next steps: rerun command, inspect lane-specific docs, and check operator evidence. |
| Information architecture | Keep docs/operator verification surfaces scannable: command first, expectation second, troubleshooting third. |

Primary focal point: canonical runtime-to-handoff command truth and lane boundaries. Secondary hierarchy: proof expectations and non-prerequisite guarantees.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | Run Runtime-to-Handoff Proof |
| Empty state heading | Runtime-to-Handoff Proof Not Run Yet |
| Empty state body | Start with `mix test.adoption` for default-lane verification, then run `mix test.runtime_to_handoff` when you need bounded handoff proof. This lane does not require semantic fast-path, knowledge, retrieval, or hosted onboarding setup. |
| Error state | Runtime-to-handoff proof failed before completion. Re-run `mix test.runtime_to_handoff`; if it still fails, compare output against operator verification guidance and confirm no optional lane setup was assumed. |
| Destructive confirmation | Remove proof evidence entry: "Delete this verification record only if you are replacing it with a newer `mix test.runtime_to_handoff` run for the same closeout window." |

Wording guardrails:

- Always name the canonical command as `mix test.runtime_to_handoff`.
- Keep `mix test.adoption` explicitly framed as the default-lane verifier, not a synonym.
- Do not imply semantic/knowledge/retrieval/hosted onboarding prerequisites for runtime-to-handoff proof.
