<interfaces>
brandbook/ does not exist yet — this plan creates it. No imports; the script is self-contained Node ESM (.mjs) using only built-ins. No npm install.

WCAG 2.1 relative luminance (the math the script must implement):
  channel: c/255 -> if <=0.03928 then c/12.92 else ((c+0.055)/1.055)^2.4
  L = 0.2126*R + 0.7152*G + 0.0722*B
  ratio = (Llighter + 0.05) / (Ldarker + 0.05)
Thresholds: PASS-AA >=4.5; PASS-LARGE/UI >=3 and <4.5; FAIL <3.
</interfaces>
