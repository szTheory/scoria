<objective>
Implement advanced UI behaviors: asynchronous token stream coalescing and Human-In-The-Loop (HITL) approval modals.

Purpose: 
1. Real-time LLM token rendering causes extreme LiveView diff traffic and CPU spikes. Server-side token buffering (~75ms chunks) safely handles fast models.
2. Tools that change state require operators to manually approve them before the executing OTP task continues.
Output: Token coalescer timer logic, `Approval` state struct, and HITL modal handling.
</objective>
