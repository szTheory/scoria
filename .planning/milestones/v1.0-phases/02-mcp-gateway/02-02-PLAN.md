<task type="auto" tdd="true">
  <name>Task 2: Implement Dynamic Schema Validator</name>
  <files>lib/scoria/mcp/validator.ex, test/scoria/mcp/validator_test.exs</files>
  <behavior>
    - Test 1: Given a tool module and valid arguments, returns `{:ok, cast_args}`.
    - Test 2: Given a tool module and invalid arguments (e.g., wrong type, missing required), returns `{:error, changeset}`.
  </behavior>
  <action>
    Create `Scoria.MCP.Validator`.
    Implement `validate_args(tool_module, raw_args)`.
    Use `Ecto.Changeset.cast/4` with a schemaless map type (`{%{}, tool_module.input_schema()}`) to validate `raw_args`.
    If valid, return `{:ok, Map.new(changeset.changes)}` (or similar). If invalid, return the error.
    Define a dummy tool module within the test file to test the validation.
  </action>
  <verify>
    <automated>mix test test/scoria/mcp/validator_test.exs</automated>
  </verify>
  <done>Arbitrary maps can be dynamically validated against a tool's defined Ecto schema.</done>
</task>
